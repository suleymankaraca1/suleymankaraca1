## Projects

### F.I.L.T.R.E
AI-powered content verification platform. Uses five custom algorithms for deterministic claim scoring without relying on generative AI, eliminating hallucination risk. Integrates NLP-based NLI models and generates structured verification reports.

### VERITAS
Multi-agent fact verification system. Orchestrator-reporter architecture with dedicated researcher agents and a source validation layer for structured, traceable claim verification.

### MediAgent
AI-powered clinical decision support system that assists physicians with diagnostic suggestions based on symptoms and test results.

### OTS — Student Tracking System
Full-stack web platform with teacher, admin, student, and parent panels. Features messaging, attendance tracking, exam results etc.

### MelodAI
AI system that generates royalty-free instrumental melodies across six emotional categories. Produces original music without vocals.

### LUNAR AI
62-million parameter language model built from scratch. Developed to understand model architecture and training pipelines from the ground up.

### Orby
Personal voice assistant running fully local. Uses Whisper for STT, a local LLM via Ollama, and edge-tts for voice output.
